# Project Infinity-X 4.0 (Android 17) for POCO X3 Pro (vayu) Builder

Automated CI/CD GitHub Actions workflow to build and port Project Infinity-X 4.0 (Android 17) for POCO X3 Pro (`vayu`).

## Components
- **Base ROM Framework**: [Project Infinity-X Branch 17](https://github.com/ProjectInfinity-X/manifest/tree/17) (Android 17.0.0_r1)
- **Device Tree**: `android_device_xiaomi_vayu` (branch `lineage-24.0`)
- **Common Tree**: `android_device_xiaomi_sm8150-common` (branch `lineage-24.0`)
- **Vendor Blobs**: `proprietary_vendor_xiaomi_vayu` + `sm8150-common`
- **Kernel Tree**: `android_kernel_xiaomi_sm8150` (branch `lineage-24.0`)
